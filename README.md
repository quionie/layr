# Layr

## Description
Layr is a clean, web-based kanban task board inspired by modern tools like Trello and Notion. It runs entirely in the browser using vanilla HTML, CSS, and JavaScript, with no build tools or dependencies.

## Features
- Three-column kanban board: To Do, Doing, Done
- Add new cards to the To Do column
- Drag and drop cards between columns
- Persistent board state via localStorage
- Responsive, mobile-friendly layout

## How to run locally
1. Clone or download this repository.
2. Open `index.html` in your browser.
